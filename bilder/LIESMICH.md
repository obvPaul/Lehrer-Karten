# Kartenbilder

Hier liegen die Fotos für die Karten. Jede Datei heißt wie die Kartennummer:

- `003.jpg` → Karte 003 (Prof. Musterfrau)
- `012.jpg` → Karte 012 (Prof. Mustermann)
- …

Ist für eine Karte keine Datei da, zeigt die Website den Platzhalter.

## Bild ändern

1. Website öffnen und `#bearbeiten` an die Adresse hängen (oder in der Fußzeile auf „Bilder bearbeiten“ klicken).
2. Auf das Bild einer Karte tippen, „Foto wählen“, Ausschnitt mit Ziehen und Zoom einstellen, „Übernehmen“.
3. „Herunterladen“ bzw. „Alle herunterladen“ – die Dateien heißen schon richtig (z. B. `003.jpg`) und haben das passende Format.
4. Die Dateien in diesen Ordner legen, committen und pushen. Danach sehen alle Besucher die neuen Bilder.

Bis zum Push sind geänderte Bilder nur im eigenen Browser sichtbar.
